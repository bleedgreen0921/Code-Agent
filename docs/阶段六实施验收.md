# 阶段六：持久任务与后台操作验收

实施日期：2026-10-15。接口、部署、限额和故障核对见 [持久任务与后台操作](持久任务与后台操作.md)。

## 交付范围

1. Task 与调度：core_0005 保存 Task、依赖、后台操作和生命周期事件；Run 关联 Task 与执行序号。创建幂等、固定能力绑定、依赖失败传播、总期限、容量等待和单 Task 单活动 Run 均在既有 PostgreSQL admission 事务中处理。API 增加 Task 查询/取消/时间线/操作查询，Run 保持既有独立执行与 Conversation 语义。
2. 本地后台命令：独立 operation 容器，固定镜像、非 root、无网络、只挂载注册工作区、资源限制和绝对期限监督。输出持续排空并限制回执、日志大小；执行结果和清理状态分别持久化，确认结果后才删除容器。当前 Task 可以继续读取和只读委派，其他 Run 不能进入重叠工作区。
3. MCP 后台任务：锁定 fastmcp-tasks 4.0.1 与 Uvicorn 0.35.0。后台连接显式注册现代 Tasks 扩展，通过官方 call_tool_task / ToolTask 保存、重建和查询句柄。同步 MCPAdapter 继续使用受限旧协议连接，不受扩展自动注册影响。静态目录、账号、凭据摘要和连接身份共同约束重连。
4. 一致性与兼容：后台记录先于外部派发；原始调用 ID 与派发 UUID 去重；数据库确认重试不会重发命令或 tools/call。独立监控租约支持 Worker 更换，未知结果失败且保留未释放占用；成功发布在同一事务内确认 checkpoint、消费标记及 Task 状态。Task 终态不被迟到结果恢复。

三个原有内置 Profile 的默认工具列表保持不变。新增配置示例 task-workspace，调用方须显式选择。未增加工作副本、回滚、Cron、Agent Teams、通用 Workflow 引擎或独立 Goal Loop。

统一入口：

```sh
python -m scripts.postgres_integration --port 55436
```

入口构建不可变执行镜像，创建随机名称、随机凭据的普通 PostgreSQL 16 测试库，迁移、bootstrap、doctor 后执行严格 pytest，校验报告非空且零失败/错误/跳过。测试结束删除数据库容器；测试 fixture 核对标签并删除测试创建的后台容器，避免断言失败遗留资源。

模型使用 SyntheticModel；远程路径使用进程内真实 MCP SDK HTTP 服务及官方 Tasks 客户端，禁止真实模型、外部 HTTP 和外部网络。项目没有启动 FastMCP 服务端调度器或 Redis。

Worker.run 端到端用例通过 API 创建依赖 Task 和后台 Task，首个 Worker 完成依赖并启动后台命令，Run 发布阶段报告后停止 Worker。新 Worker 核对原容器，持久化和清理后只创建一次续 Run，继承成功消息、注入未消费结果并发布最终 Task 答案。远程路径使用独立连接和原生 Tasks 句柄完成相同的结果续执行链路。

## 使用边界

后台期间工作区读取没有一致快照保证。命令失败、Task 取消或超时不会回滚工作区及外部副作用。远程取消只表示协作请求，必须核对终态；无法确认释放仍计入占用。unknown Task 不自动重试，也不会因迟到结果恢复。测试使用受控服务和合成模型，不替代实际模型效果评估或具体远程服务的重连接入验收。
