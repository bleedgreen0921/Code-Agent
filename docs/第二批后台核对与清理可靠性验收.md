# 第二批：后台核对与清理可靠性验收

实施日期：2026-10-16。对应[总计划](异常处理与执行一致性增强计划.md)，行为与部署契约见[第二批说明](第二批后台核对与清理可靠性.md)。基线为 core_0006、310 项既有测试；Git 基线 `5cebe888b2141c564d13bee030a37bfe88650a24`，本批代码保存在工作区，未提交。

## 交付范围

1. 严格 reliability 服务端配置与逐 MCP 后台工具的 cancel_retry_safe；策略进入 Profile 指纹、操作冻结绑定和运行快照。默认 false 保持原有同步工具清单。
2. core_0007 只扩展后台操作表，持久化观察预算、崩溃中轮次、远程轮询下限和取消尝试/确认；保留历史结构签名，运行角色不增加 DDL 权限。
3. Docker/MCP 原资源观察白名单、跨 Worker 预算、幂等提交确认、次数/窗口耗尽与 Task 原子失败；未知后的低频核对仅补事实。清理动作前重核原身份和授权。
4. 取消意图、预留尝试与服务端确认独立；默认最多一次，冻结授权且记录为瞬时传输失败才允许至多三次，每次先查状态。历史取消保守占用一次，接收仍未确认。
5. 有效执行期限贯穿准备、graph、摘要、子 Agent、工具和后台派发；共享清理截止时间、一次发布预留、本地已确认租约监督；清理与失败确认不重新获得完整预算。
6. 维护连接故障有限恢复、等待可停止、故障期间停止 admission、预算耗尽非零退出与有界最终心跳；只读诊断和安全日志扩展。

未增加业务调用/后台启动重试、异常 Run 重放、失败 Task 恢复、工作区回滚、恢复 CLI、强制解锁接口、验证器或循环控制。依赖及锁文件保持基线版本。

## 验收方式与覆盖

统一入口为 `python -m scripts.postgres_integration --port 55436`。实际隔离 PostgreSQL 16、不可变 Docker 执行镜像、SyntheticModel 和真实原生 MCP SDK HTTP 服务；测试入口阻断真实模型及外部 HTTP。JUnit 必须非空，失败、错误、跳过均为零。

| 验收组 | 证据 |
|---|---|
| 配置和安全分类 | 严格整数、有限正时间、退避上限、未知配置字段；同步工具拒绝取消授权；Profile 仅绑定已选工具；明确瞬时/永久异常及全叶子异常组 |
| 预算和调度 | 首次计数、5 次上限、30 秒窗口不延长、成功清零、完整重复确认、确定性抖动边界；远程间隔首次即生效，窗口/执行期限到期可唤醒但不提前查询 |
| 跨 Worker | inflight 只扣一次，孤立轮次耗尽和 Task 失败同事务可见；次数、窗口、远程间隔和取消事实跨监控租约保留 |
| 数据库确认 | 观察开始/完成、取消预留/确认四个位置实际提交后丢回执，重试完整确认且不重复扣减 |
| Docker 副作用 | daemon、inspect、logs 两次瞬时失败后恢复，真实命令文件只追加一次；既有 create/start/rm 丢回执、身份、结果及清理测试保留 |
| MCP 副作用 | 真正连接协商和 tasks/get 传输故障恢复，tools/call 与业务副作用始终一次；401/403 立即停止；原句柄/账号/协议/结果 schema 既有断言保留 |
| 未知后收敛 | 迟到结果只补事实，不恢复 Task、不消费结果、不创建 Run；缺失句柄不建连且不虚构成功观察；已确认执行及 released 占用不可倒退 |
| 取消窗口 | 意图后崩溃、预留后未发、传输失败、确认、协议失败；默认一次/安全三次、跨进程计数、每次先状态查询；接受后仍活动不重复取消，窗口到期 unknown；取消/完成竞争保留 |
| 执行期限 | 无资源、Docker、MCP、混合预留与子 Agent 继承；预算不足初始化/模型不启动；既有模型、Shell、文件、摘要、子 Agent 控制场景保留 |
| 清理与发布 | Docker 清理不翻倍，发布确认丢失不重跑；既有清理前禁止发布、清理中续租、失租禁止发布及 MCP 数据库失败仍断连场景保留 |
| 维护与租约 | 瞬时恢复、5 次耗尽、永久错误立即暴露、退避/数据库等待响应停止；实际 PostgreSQL 后端在等待维护锁时被终止后由连接池重连；续租不可用时按最后确认租约取消执行 |
| 迁移与只读 | 空库、core_0006 升级、历史取消迁移、重复迁移、保留绑定/错误/结果/占用、结构漂移拒绝与运行角色无 DDL；原有只读快照与安全日志测试保留 |

保留全部既有场景及业务断言。必要的测试夹具调整为：短 Run 总时间增加新清理/发布预留，保留原执行时间；MCP close 拦截器接收共享截止时间；历史核对推进两个轮询时间字段；新策略指纹纳入明确公式，legacy 迁移仍与 core_0002 的原冻结绑定比较，绝不按当前默认绑定回填历史。
