# 阶段三实施验收

2026-10-15，实现复杂任务的上下文与进度。保留标准 create_agent、原生 messages reducer、PostgreSQL Checkpointer 和当前框架版本；不新增数据库表或迁移。

## 交付行为

- workspace_read/workspace_write 按 Run 启用原生 TodoListMiddleware；简单任务可直接回答，chat 仍为空工具。清单最多 20 项、每项 200 字、序列化 8 KiB。非法、超限及同响应重复更新不会写入错误状态。Todo 是模型维护的进度，不代替验证和最终答案。
- 注册表保存标准工具声明，Worker 合并显式工具与中间件生成工具，以本轮真实实例绑定权限；重复、未声明或 Schema 不一致在模型调用前失败。可信直接工厂默认允许传入中间件工具，使用框架自身状态组合。
- 生命周期限制 ToolMessage 和 Command.update.messages 的正文，保留 Todo、自定义状态、路由、调用 ID、状态与 artifact。字典 artifact 补充 truncated，任意其它 artifact 保持原值；内存工具同样使用有效输出限制。
- [skills].directories 注册绝对目录，解析直接子目录 SKILL.md 的安全 YAML frontmatter 与 UTF-8 正文；启动拒绝重复名称/键、非法元数据、越界链接、特殊文件、超长正文或技能清单。只读不可变内存快照，不执行脚本或自动展开附属资源。
- 自定义 Profile 通过 tools/skills 显式选择能力和白名单。内置工作区 Profile 可读全部注册技能；空目录不暴露 read_skill。初始模型请求仅有名称/描述，正文由 read_skill 按需读取，artifact 保存名称与正文哈希。allowed-tools 等元数据不授予权限。
- 技能名称、描述、正文哈希和实现版本绑定引用它的 Profile；未引用技能变更不影响自定义 Profile，默认 chat 保持阶段二的精确绑定计算。磁盘修改不影响已有快照；重启后的绑定变化使用 CONFIGURATION_CHANGED。
- 主模型调用前在扩展 Hook 之后重新注入可信 Profile 提示、工作区模式、工具范围、无网络、期限、失败不回滚、技能目录与当前 Todo；不写入持久消息。history_tokens_approx 与 request_tokens_approx 分别估算历史和含系统/工具 Schema 的请求。
- 原生摘要模板仅附加代码任务保留提示，默认触发/近期保留/输入裁剪为 20000/6000/16000 token；20000 不是模型上下文窗口硬上限。保留原生分段、配对和最多三次摘要尝试；主模型 16 次与工具 10 次配额不变。
- 继承入口白名单只有 messages，要求同会话上一成功 Run 的明确最终 checkpoint_id 和正确 thread_id；当前 Todo、计数、业务状态、结构化结果和资源不继承。历史技能/Todo 消息不会恢复状态或扩大权限。
- 修复现有 HTTP/CLI trace 对原生 Send 的 JSON 序列化，使含工具调用的 checkpoint 与 Todo 可通过原入口诊断；不增加进度字段或端点。
