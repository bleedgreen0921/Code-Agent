已实测的关键断言：

| 场景 | 核对 |
|---|---|
| 脏工作区 + unittest | 当前文件、staged/unstaged/untracked 分离；报告引用实际读行；真实 passed |
| 历史提交 + pytest | 原目录 HEAD 已改变，读取/测试仍针对目标 SHA；干净快照 index |
| 检查失败/超时 | 原记录为 failed/inconclusive；Agent 继续输出正式分析，报告保留限制 |
| 静态分析 | 无检查集仍完成，正式 Markdown 显示未配置、未执行 |
| 无效报告 | 未读取行号被 ToolStrategy 反馈；同一图纠正，Run 仅执行一次 |
| 写入权限 | /tmp 可写，/workspace 写入失败；无 socket、服务 DSN 和产物目录 |
| SIGKILL | 实际进程被杀；失租后新核对清理主/检查容器，不重放 Run |
| 确认丢失 | 原检查 ID 不变，结果写入重试；预留未确认不启动第二次检查 |
| Docker 不可用 | 未释放记录可诊断且继续占用；禁止正式报告；恢复后清理 |
| 原目录 | 端到端前后文件内容/模式、Git index、HEAD、引用摘要一致 |
| GC | 活动依赖阻止删除；批次持续推进；回收孤立文件；过期 410、跨任务 404 |
| 报告预算 | 引用反复无效时耗尽原模型预算，Run 不重建、不发布正式报告 |
| OOM | 真实检查超过容器内存限额后为 inconclusive，分析容器继续并发布限制 |
| 缺失挂载绑定 | 拒绝使用原目录回退；模型不被调用 |
