# 代码能力阶段四：固定可信 Python 门禁

先按 examples/python-repair/README.md 创建独立 Git 副本并注册为 `project`。
本门禁只适用于该示例的 sample.py，不是通用项目适配器。

部署准备：

```bash
python -m scripts.build_execution_image
# 将输出的不可变 sha256 镜像 ID 和两个绝对路径填入独立配置副本
export AGENT_RUNTIME_CONFIG=/absolute/path/to/runtime.code.checked.toml
python -m db.config_check --role agent-api
python -m db.config_check --role agent-worker
# 按现有部署流程重启 API 与 Worker
```

配置源为 config/runtime.code.checked.example.toml；使用已有数据库和模型环境配置。
API、Worker、配置检查均从 Registry.from_env 加载。显式声明 code-fix-checked 才注册
required 验证器、10 秒共享验证窗口和固定 python-first-n v1 定义。检查能力及资产指纹写入镜像标签；
Worker 配置检查与 Run 准备均校验它们，API 解析不访问 Docker。普通 code-fix 不需要新镜像能力。
无需数据库迁移；继续使用 core_0008。TOML、HTTP 请求中均无检查命令或 no_progress 授权字段。

任务选择 `profile=code-fix-checked, workspace_id=project`。其工具和 code-fix 相同，复用 code-fix Skill。
开发期间可通过真实 Shell 反馈继续修复；Agent 返回后不会再调用模型。正式门禁不读取开发测试或通过标志。
检查结果通过已有 Run/Task 查询中的 verification 字段返回，原始答案不会被验证器改写。
失败和取消不回滚文件，不自动重放 Run。普通 code-fix 保留原完成语义且不生成正式报告。

可信 Python 扩展可以用 `dataclasses.replace` 显式开启 no_progress_enabled；默认关闭。
不通过配置字符串动态导入扩展；注册点为 agent_service/profiles.py 的 Registry.from_env。
扩展的 checks 仅由可信 Python 构造；缺定义、权限或允许的注册工作区时立即拒绝。
绑定及运行配置快照包含非空检查定义、版本、测试 ID、固定 argv、工作目录和资产内容指纹。

`VerificationContext.run_check(check_id)` 只对当前 Profile 已注册检查有效，不是模型工具。
它同时检查 Shell 和源码读取权限，并复用对应授权校验器、当前容器、命令锁、健康检查、
Docker 进程句柄、输出上限及清理机制。上下文关闭后拒绝访问；未消费的检查会被撤销并在原清理流程收敛。
验证器省略必需检查，或丢弃失败结果，都不能发布 passed。

固定资产位于容器只读目录 /opt/agent/checks。监督进程按固定路径读取 sample.py（最多 1 MiB），
核对控制器观察哈希，把该版本源码交给隔离 Python 子解释器编译执行；不加载候选 pyc 或工作区替代模块。
六项固定断言在监督进程执行：零长度、正常截取、空输入、超长、负数拒绝、不修改输入。
子解释器输出单独限流；监督进程输出唯一结构化回执。控制器严格校验关联、整数类型、
资产、测试 ID、计数和退出状态。零测试、遗漏或跳过必需测试均为 inconclusive。

只观察及复核 sample.py，不声称获得全工作区快照或完整代码覆盖。
执行前观察、固定检查、回执处理及文件结束复核共享原 10 秒验证定时器，也受剩余 Run 时间和单命令期限约束。
每项候选调用有 1 秒内部上限；候选超时为 inconclusive。候选子进程及脱离进程组的后代由监督进程收敛；
现有阶段报告或未收敛资源不启动通过门禁。超时、取消和失租最终仍由原 Run 清理流程处理。

passed 仍需文件复核、资源清理和原发布事务全部满足。断言或候选代码错误映射 VERIFICATION_FAILED，
无法确认映射 VERIFICATION_INCONCLUSIVE，非法回执映射原验证契约错误。取消、失租、Run 期限及容器丢失
继续传播控制异常。提交确认丢失只重查数据库，不重复模型、验证器或检查。

验收入口仍为 `python -m scripts.postgres_integration`，禁止真实模型和外部 HTTP。
