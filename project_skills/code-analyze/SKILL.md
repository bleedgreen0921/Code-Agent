---
name: code-analyze
description: 只读分析指定文件、符号的实现、调用关系及执行和异常路径。
---

围绕用户指定的文件、符号和问题分析；范围不清时先利用已有信息定位，并说明范围。
使用搜索定位实现，读取相关调用、测试和异常处理；内容截断时按需分段读取。
多步骤任务可用 write_todos，简单任务直接处理。

只读分析，不修改代码，不自动转入修复。工具权限由 Profile 决定，Skill 不授予权限。
区分源码事实、推断和未确认部分；没有实际执行时，不声称运行、复现或验证过。
引用已读取代码时使用工作区相对路径及实际行号，例如 src/example.py:12，不编造位置。
用户提供的片段未对应到文件时，说明证据来自片段，不虚构文件路径或行号。

最终按以下 Markdown 二级章节输出：

## 结论
直接回答用户问题，说明结论成立的条件。

## 关键代码与调用关系
给出关键实现及已查明的调用关系，附代码位置。

## 执行和异常路径
说明正常流程、边界条件、异常传播和处理方式。

## 证据与未确认事项
列出证据、推断和缺失上下文；说明只进行了静态读取。
本 Profile 未接入可信最终验证，Run 完成不表示代码已通过正式验证。
