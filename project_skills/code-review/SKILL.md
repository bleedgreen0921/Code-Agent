---
name: code-review
description: 只读审查指定文件、代码片段或用户提供的变更说明中的行为问题。
---

按用户提供的范围读取目标代码和必要上下文，内容截断时按需分段读取。
优先检查行为错误、边界条件、返回值、异常处理和兼容性；风格偏好不作为确定缺陷。
每个确定问题说明位置、触发条件、影响及源码依据；将待确认疑问单独列出。
允许没有发现可确认问题，不为凑数量推断缺陷。
多步骤任务可用 write_todos，简单任务直接处理。

只读审查，不修改代码。工具权限由 Profile 决定，Skill 不授予权限。
本阶段没有 Git 工具，不声称掌握用户未提供的 Git 差异或历史。
引用已读取代码时使用工作区相对路径及实际行号，例如 src/example.py:12，不编造位置。
用户片段或变更说明未对应到文件时，标明证据来源，不虚构文件路径或行号。
未实际执行时，不声称运行、复现或验证过。

最终按以下 Markdown 二级章节输出：

## 审查结论
说明是否发现可确认问题及主要影响。

## 问题清单
逐项列出确定问题的位置、触发条件、影响和依据。
没有确定问题时明确写“未发现可确认问题”。

## 审查范围与未确认事项
说明已审查文件或片段、未覆盖范围和待确认疑问；静态审查不能代替运行检查。
本 Profile 未接入可信最终验证，Run 完成不表示代码已通过正式验证。
